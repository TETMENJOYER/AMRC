# Геометрия и устройство программы

## Поток расчёта

1. Входной JSON описывает 2D-область либо замкнутый 3D-блок, изделие и ограничения резов.
2. Для блока выбираются допустимые исходные установки и направления параллельных резов.
3. Для каждого слэба строится область, в которой изделие помещается по всей толщине.
4. Поиск рядов, tabu-переходы, пакетный Adam и L-BFGS ищут большее количество изделий.
5. Допустимые кандидаты проходят независимые 2D- и полные объёмные проверки.
6. Выбранный план может пройти доводку направлений и кромок при фиксированном количестве.
7. Результат проверяется и экспортируется; сохранённый JSON можно перепроверить командой `verify`.

## Геометрическая модель

Блок хранится как замкнутое тело с треугольной поверхностью и сохраняет
невыпуклость. Синтетические блоки также содержат рецепт построения.
Модель материала — сплошной однородный камень. Единицы — миллиметры.
`Frame` задаёт переход между исходными, локальными координатами слэба и станком.

Пусть K — полный блок, B — ограничивающий прямоугольник проекции слэба,
P — призма B на всю толщину. Вычисляется отсутствующий материал A = P \ K.
Допустимая область D = B \ projection_xy(A). Поэтому изделие над D помещается
в полном интервале толщины. Сечения, построенные для изображения, не заменяют
этот критерий: между сечениями может находиться сужение.

Область D может иметь отверстия и несколько компонент даже без внутренних
полостей в исходном камне. Выпуклая оболочка используется как вспомогательная
рамка поиска и для опорных контактов; она не заменяет исходную форму.

## Поиск и доводка

Изделия имеют отношение сторон 3:1. Центры и углы оптимизируются в нормированных
координатах; независимая проверка возвращается к физическим миллиметрам.
Геометрические штрафы направляют поиск, но не определяют окончательную допустимость.
Tabu-память сравнивает раскладки с учётом перестановки одинаковых изделий.

Поиск блока распределяет общий бюджет между установками, планами и слэбами.
План выбирается по общему количеству изделий, затем по меньшему числу резов.
Эвристическая неудача поиска N изделий не доказывает невозможность такого N.

Доводка сохраняет количество в каждом слэбе, изделие, исходный установ,
план резов и объёмный баланс. Сначала согласуются направления, затем кромки.
При принятии предложений угловые показатели защищены от ухудшения.
Политики `adaptive` и `always` выбираются явно; адаптивная политика поиска
количества и адаптивная политика доводки — разные механизмы.

В CLI поисковых команд доводка включена по умолчанию. Для отдельного измерения
поиска используйте `--alignment-seconds 0`. В библиотечных конфигурациях поиска
`alignment_seconds=0` отключает её по умолчанию.

## Независимая проверка

2D-валидатор заново строит прямоугольники по центрам и углам: область должна
покрывать изделия, внутренности изделий не должны пересекаться. Касание разрешено.
Диагностические допуски не превращают нарушение в допустимость.

3D-валидатор проверяет полный объём каждого изделия относительно исходного
блока и назначенного слэба, взаимные пересечения, план резов и баланс объёмов.
Любой непустой остаток CSG-разности изделия и блока отклоняется.
Проверки только центров или восьми углов недостаточно.
Сохранённые флаги допустимости и вершины не заменяют реконструкцию.

Проверки численные и используют GEOS/Manifold; формальный сертификат
оптимальности или точной арифметики не выдаётся.

## Ограничения станка

`vertical_fixed_setup` использует один устойчивый исходный установ и поворот
вокруг Z до серии. Плоскости резов вертикальны в координатах станка.
Устойчивость оценивается по центру масс полного блока и контактной опоре
до начала распила. После каждого реза она не пересчитывается: процесс
предполагает удерживающие перемычки до механического разделения.

Перемычки, дефекты материала, пропилы, припуски и потери при разделении
не моделируются; поддерживаются нулевые пропилы и припуски.
Начальная обрезка не разрешена. Метрики ровности не являются числом реальных
проходов пилы, маршрутом резки или точностью станка.
Запас опоры в примере — параметр задачи, а не производственный допуск.

## Основные модули

| Модули | Назначение |
| --- | --- |
| `block`, `mesh_import`, `block_generator` | Исходное тело и подготовка геометрии |
| `machine`, `cut_plan`, `plane_clip`, `slab3d` | Установ, резы, согласование новых граней, область полной толщины |
| `problem`, `geometry`, `seeds`, `local`, `tabu`, `solver` | 2D-поиск и локальная оптимизация |
| `packing3d`, `block_solver` | Связь 2D-поиска с полным блоком |
| `alignment`, `adaptive_alignment`, `postprocess` | Доводка сохранённых раскладок |
| `verify`, `verify3d`, `verify_block` | Независимые проверки |
| `report`, `report3d`, `report_block`, `cli` | Экспорт и команды |
| `benchmark`, `performance`, `profiling` | Сравнения и измерения |

`sections` работает с заданными выпуклыми сечениями и проверяет каждое из них;
геометрия между измеренными сечениями этим режимом не восстанавливается.
