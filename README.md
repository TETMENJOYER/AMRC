# AMRC — оптимизация раскроя каменного блока

AMRC ищет раскладки одинаковых прямоугольных изделий в каменных слэбах и
планы параллельного распила трёхмерного блока. Python-пакет называется `rockcut`.
Сначала программа увеличивает количество изделий, затем может согласовать
их направления и кромки, сохраняя найденное количество.

## Возможности

- Раскладка в выпуклом или невыпуклом `Polygon` / `MultiPolygon` с произвольными углами изделий.
- Вычисление допустимой области слэба по всей его толщине из полного 3D-блока.
- Поиск параллельного плана слэбов и, при включённой модели станка, устойчивого исходного положения блока.
- Доводка сохранённой раскладки при фиксированном количестве изделий.
- Независимая проверка результатов и экспорт JSON, CSV, HTML, изображений и 3D-геометрии.

Поиск эвристический: найденная допустимая раскладка не считается доказанным
оптимумом. Верхняя граница по площади отдельной области не доказывает
оптимальность плана всего блока.

## Начало работы

Нужен Python 3.11 или новее. Для 3D-режимов установите дополнительные зависимости:

```sh
git clone https://github.com/TETMENJOYER/AMRC.git
cd AMRC
python -m venv .venv
# Активируйте окружение по инструкции в QUICKSTART.md.
python -m pip install -e ".[geometry3d]"
python -m rockcut solve examples/slab.json --seconds 10 --seed 42 --alignment-seconds 0 --output outputs/first-layout
python -m rockcut verify outputs/first-layout/result.json
```

Откройте `outputs/first-layout/report.html` в браузере. Параметр
`--alignment-seconds 0` отключает доводку в этом коротком примере;
без него поисковые команды включают её по умолчанию.

## Команды

| Команда | Назначение |
| --- | --- |
| `python -m rockcut solve INPUT.json` | Разместить изделия в заданной 2D-области |
| `python -m rockcut slab INPUT.json` | Найти раскладку в одном слэбе полного 3D-блока |
| `python -m rockcut block INPUT.json` | Найти план параллельных резов и раскладки всех слэбов |
| `python -m rockcut align RESULT.json` | Довести сохранённые раскладки без повторного поиска количества |
| `python -m rockcut verify RESULT.json` | Перепроверить сохранённый результат |

Параметры каждой команды: `python -m rockcut COMMAND --help`.
`--seconds` задаёт бюджет поиска; аудит и экспорт требуют дополнительного времени.
Доводка останавливается по изменению метрики или пределу раундов и может
занимать существенно больше времени, чем поиск.

## Модель задачи

Единицы — миллиметры, углы сохранённых раскладок — радианы. Отношение сторон
изделия фиксировано: 3:1. В одном расчёте используется один типоразмер.
Пропилы и припуски равны нулю; касание разрешено, пересечение внутренностей — нет.
Ненулевые пропилы и припуски валидаторы не поддерживают.

В режиме `vertical_fixed_setup` выбирается один устойчивый установ блока и
поворот вокруг вертикали до начала серии. Все плоскости резов вертикальны
в координатах станка; установка между резами не меняется. Прочность удерживающих
перемычек, потери при разделении, дефекты камня и исполнимый маршрут пилы
не рассчитываются. Это геометрический инструмент, а не готовая программа станка.

Гранитный пример содержит реконструированное основание скана и условный масштаб.
Подробности подготовки и лицензия модели — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Состав репозитория

| Каталог | Содержимое |
| --- | --- |
| `rockcut/` | Поиск, геометрия, проверка и экспорт |
| `examples/` | Входные JSON, контрольная раскладка и тестовая модель |
| `tests/` | Геометрические и функциональные тесты |
| `benchmarks/` | Переносимые задачи для сравнения стратегий и устройств |
| `scripts/` | Подготовка модели, профилирование и проверка экспорта |

Отчёты создаются при запуске и не входят в репозиторий.
Зависимости объявлены в `pyproject.toml`; конкретное GPU-окружение выбирается
под доступное оборудование. `--device auto` использует CPU, CUDA включается явно.

Тесты: `python -m unittest discover -s tests`. CUDA-тесты пропускаются,
если CUDA недоступна. Сведения о лицензии сторонней модели не устанавливают
лицензию исходного кода проекта.
