# Third-party model

The original model in `examples/models/granite_block_original.glb` is:

- **Granite block** by [matousekfoto](https://sketchfab.com/matousekfoto).
- Source: [Sketchfab model](https://sketchfab.com/3d-models/granite-block-ffb822afb855487885addfa7dfe13ac2).
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

The same model is embedded in the granite example inputs and the frozen
performance reference. For those derived inputs, the open bottom was clipped
and closed with a planar face; coordinates were converted to millimetres and
translated. The assumed physical scale has not been confirmed by measurement.
The preprocessing operations and source checksum are recorded in the input
provenance. `scripts/prepare_granite.py` contains the preparation procedure.

These model credits do not assign a license to the project's own source code.
