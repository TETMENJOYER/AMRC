# Переносимые 3D-контроли и измерения

`suite.json` описывает 11 задач и SHA256 их файлов. В `cases/` находятся
геометрия, исходные допустимые раскладки и параметры нагрузки.
`sources/granite-reference.json` содержит только геометрию исходного блока,
параметры изделия и направление плана. Журнал расчёта не требуется.

Набор включает пять гранитных слэбов, три масштаба L-образной призмы,
нерегулярную призму, слэб с раздельными компонентами и форму с узким выступом.
Начальные количества — контрольные допустимые состояния, а не доказанные максимумы.
Загрузчик проверяет SHA256 перед использованием. Изменение геометрии требует
отдельного набора и новых контрольных сумм.

## CPU и CUDA

Установка описана в [QUICKSTART.md](../../QUICKSTART.md). Для CUDA нужна
совместимая сборка PyTorch и драйвер; конкретная модель GPU не обязательна.

```sh
python -m scripts.benchmark_devices --devices cpu --mode micro --repeats 3 --adam-steps 10 --output outputs/device-micro
python -m scripts.benchmark_devices --devices cpu cuda --mode quality --solver-seconds 6 --seeds 101 202 --output outputs/device-quality
```

`micro` измеряет штрафы, градиенты, Adam, L-BFGS и передачи данных.
`quality` сравнивает число изделий и допустимость при одинаковых исходных
состояниях, seed и бюджете. Недоступная CUDA пропускается; проверьте список
фактически измеренных устройств в результатах.
Экспортированные раскладки перепроверяются по 2D и полному 3D-объёму.

## Профиль доводки

```sh
python -m scripts.profile_alignment --ids granite_slab_14 granite_slab_22 --device cpu --mode nested --steps 10 --max-rounds 1 --output outputs/alignment-profile
```

Команда берёт начальные состояния из самого набора. Это короткий диагностический
прогон; для полной доводки уберите ограничения `--steps` и `--max-rounds`.
Режимы `ordinary`, `nested`, `cprofile` разделяют обычное измерение, вложенные
таймеры и профиль функций. Используйте отдельные выходные папки.

## Профиль полного блока

Сначала создайте результат команды `block`, затем передайте его явно:

```sh
python -m scripts.profile_block --reference outputs/demo-block/result.json --seconds 30 --output outputs/block-profile
```

Для создания собственного контрольного набора по результату блока:

```sh
python -m scripts.prepare_performance_controls --reference outputs/granite/result.json --output outputs/custom-controls
```

Генератор выбирает гранитные слэбы 3, 6, 14, 20 и 22; входной план должен
содержать их все. Для загрузки другого набора у `benchmark_devices` есть `--suite`.

## Правила измерения

Используются float64, один CPU-поток, отдельный прогрев и синхронизация CUDA
на границах измерений. Вложенные CUDA-таймеры измеряют время на стороне CPU
с ожиданиями, а не длительность отдельных ядер. Вложенные inclusive-времена
нельзя суммировать: для суммы фаз используйте exclusive-времена.

Профилирование добавляет накладные расходы и может менять траекторию поиска
с ограниченным бюджетом. Измеряйте ускорение обычными парными запусками,
отдельно от cProfile. Ускорение Adam не означает ускорения всей 3D-задачи.
Измерения создают локальные сведения об окружении; проверяйте их перед
публикацией результатов.
